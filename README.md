# 陪陪刷 - 公考人的 AI 学习笔记本

**陪陪刷** 是一款面向中国公务员考试（行测）的 Android 智能学习应用。

它不只是一个悬浮搜题工具。每次截图、每道错题、每条题库解析和每张知识卡片，都会进入同一本“备考笔记本”：先成为可整理的资料源，再转化成结构化解析、复习笔记和当天可执行的学习任务。

```text
截图 / OCR / 题库 / 错题 / 知识卡片
-> 资料源
-> AI 解析 + 题库原解析
-> 错题笔记 / 知识卡片 / 名师视角
-> 复习、计划和专注
```

---

## NotebookLM 式学习体验

陪陪刷把分散在刷题、查词、错题整理和复习里的信息，收进一条连续的学习链路。

| 学习体验 | 陪陪刷里的对应能力 |
| --- | --- |
| 收集资料源 | 悬浮球截图、OCR、题库 JSON、错题和知识卡片 |
| 围绕资料源理解 | 题库原解析与 AI 解析并列对读 |
| 形成自己的笔记 | 错题详情、知识卡片、标签和复习状态 |
| 换一个视角重讲 | 名师模式、题型 Prompt 和多轮 AI 分析 |
| 把理解变成行动 | 学习计划、番茄钟、应用拦截和复习记录 |

## 核心功能

### 悬浮球：把屏幕上的题目收进笔记本

- **一键截图识别**：点击悬浮球即可截取屏幕内容，自动 OCR 识别题目文字
- **AI 深度解析**：将识别结果发送给 AI 模型（默认 DeepSeek），获取结构化答案解析
- **静默搜题**：小悬浮球模式可在后台静默截图，点击后一次性展示结果
- **多种截图模式**：支持固定区域截图和自定义框选
- **图形推理支持**：图形推理题型可升级为多模态识图分析

### AI 解析：让答案变成可理解的讲解

- **多轮分析**：围绕题目、选项和上下文组织分析过程
- **资料对读**：同时保留题库原有解析和 AI 解析，便于对照判断
- **题型适配**：针对不同行测题型使用不同的分析和讲解方式
- **结果沉淀**：解析结果可进入错题本，成为后续复习的资料源

### 词典识词：从题目里顺手完成词语积累

- **悬浮菜单快捷入口**：长按悬浮球进入词典识词，截图后自动识别选项中的成语和词语
- **题库联动**：优先匹配本地题库原题，再从选项中提取词语进行查询
- **海量词库**：内置 30,000+ 成语、16,000+ 汉字、260,000+ 词语和 14,000+ 歇后语
- **实时搜索**：支持中文、拼音和缩写等多维检索

### 题库：可检索、可导入的备考资料库

- **自行导入真题**：覆盖行测六大模块，支持自定义导入题库 JSON
- **全文检索**：FTS5 中文分词与 BM25 相关性排序，快速匹配题目
- **模块化管理**：常识判断、言语理解、数量关系、判断推理、资料分析和政治常识
- **练习模式**：按模块、正确率区间筛选题目，组织专项训练

### 错题本：把一次失误整理成一页可复盘的笔记

- **自动录入**：OCR 识别后自动搜索题库，命中时保存结构化数据，未命中时保留 OCR 文本
- **双解析对比**：题库解析与 AI 解析可通过 Tab 切换查看
- **来源保留**：同时保留题目文本、截图和解析，避免丢失原始语境
- **长截图导出**：将错题详情导出为长图片，保存到相册或分享

### 知识卡片：把题目背后的知识单独记下来

- **分类管理**：成语、时政、政治理论、申论、常识、人物素材和面试素材
- **关键词搜索**：快速检索卡片内容
- **导入导出**：支持 JSON 格式的数据备份与恢复
- **持续完善**：分类整理、复习状态和更完整的知识工作流仍在迭代

### 学习计划：把“看懂了”安排成“做完了”

- **日历视图**：按日期管理学习任务，支持普通、重要和紧急优先级
- **时间线展示**：直观查看每日任务安排
- **完成统计**：追踪每日学习进度
- **持续完善**：更细致的任务拆解和复习调度仍在迭代

### 番茄钟：给理解和复盘留出完整时间

- **专注计时**：可配置工作和休息时长，支持长休息间隔
- **应用拦截**：专注期间自动屏蔽非白名单应用，减少打断
- **白噪音**：规划雨声、咖啡馆和森林三种环境音
- **任务绑定**：规划将番茄钟与学习计划关联，追踪专注时长

### 名师模式：换一位老师重新讲同一道题

- **多教师支持**：内置番茄等名师解题风格，也可自定义导入教师配置
- **题型适配**：覆盖片段阅读、逻辑填空、语句表达、图形推理、定义判断、类比推理和逻辑判断
- **自定义提示词**：每种题型可配置专属 AI 分析提示词
- **待完成**：图形推理视觉模式和更完整的名师切换体验仍在开发

## 技术架构

```text
单 Activity + Fragment + 前台 Service
├── MainActivity（底部导航：首页 / AI模型 / 知识卡片 / 计划 / 番茄钟）
├── ScreenCaptureService（核心前台服务）
│   ├── +Ball.kt        悬浮球拖拽/点击/菜单
│   ├── +Capture.kt     MediaProjection 截图
│   ├── +Result.kt      结果卡片展示
│   ├── +Renderers.kt   教师风格渲染器
│   └── +Notify.kt      通知管理
├── AI 管道
│   ├── OpenAIApiService    多协议 AI 客户端（OpenAI/Anthropic/Gemini）
│   ├── MultiPassAnalyzer   多轮分析编排器
│   ├── CloudOcrClient      云端 OCR
│   └── PaddleOCR v5        本地 OCR（NCNN）
├── 数据层
│   ├── QuestionBankDb      FTS5 全文检索题库
│   ├── DictionaryDb        词典数据库
│   ├── KnowledgeCardDb     知识卡片
│   ├── PlanDb              学习计划
│   └── PomodoroDb          番茄钟记录
└── 工具
    ├── AppPreferences      配置持久化
    ├── TeacherManager      教师配置管理
    └── ModelManager        AI 模型管理
```

## 快速开始

### 安装

从 [Releases](https://github.com/HuiYeJi-7/Pei-Pei-Shua/releases) 下载最新 APK 安装。

### 首次使用

1. 打开 App，授予悬浮窗和录屏权限
2. 点击“开启悬浮球”
3. 切换到任意做题 App，点击悬浮球截图分析
4. 长按悬浮球打开菜单：词典识词、截图选区、切换名师等

### 设置 AI 模型

1. 进入 **AI模型** 页面
2. 填写 API 地址（默认 DeepSeek）、API Key 和模型名称
3. 点击保存

### 自定义题库

题库 JSON 格式：

```json
[
  {
    "key": "唯一ID",
    "title": "题目内容",
    "options": [
      {"text": "A选项"},
      {"text": "B选项"}
    ],
    "answer": "A",
    "analysis": "解析内容",
    "knowledge_point": "知识点"
  }
]
```

在设置页面点击“导入题库”，选择 JSON 文件即可。
